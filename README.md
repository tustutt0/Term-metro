# Termômetro
Esse projeto foca na produção de um termômetro de baixo custo utilizando apenas impressão 3D e eletrônicos usuais para
conseguir medir a temperatura do ambiente.
 As mudanças de temperatura ao longo do dia podem tornar ambientes como quartos, salas de estudo e escritórios desconfortáveis, prejudicando atividades rotineiras, como estudar, trabalhar e dormir. Muitas vezes, as pessoas não sabem a temperatura real do ambiente e acabam ligando ventiladores ou aparelhos de ar-condicionado sem avaliar se isso é realmente necessário.
Por isso , esse projeto foi criado, para auxiliar no controle do conforto térmico, que está cada vez mais difícil de ser satisfeito.
